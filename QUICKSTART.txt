📌 SYSTEM REQUIREMENTS:
  • Python 3.8 or higher
  • pip (Python package manager)
  • ~500MB disk space for dependencies

═══════════════════════════════════════════════════════════════════════════════
                            STEP-BY-STEP SETUP
═══════════════════════════════════════════════════════════════════════════════

STEP 1: INSTALL PYTHON
───────────────────────
• Windows: Download from https://www.python.org/downloads/
  ✓ Make sure to check "Add Python to PATH" during installation
  
• macOS: brew install python3
• Linux: sudo apt-get install python3 python3-pip

Verify installation:
  python --version
  (should show Python 3.8+)


STEP 2: SETUP ENVIRONMENT
─────────────────────────
1. Navigate to the project root directory
2. Edit the .env file with your Discord Bot Token:
   
   .env file:
   ─────────
   DISCORD_TOKEN=your_actual_discord_token_here
   PORT=5005
   DEBUG=False

   📍 Get Discord Token:
      • Go to Discord Developer Portal: https://discord.com/developers/applications
      • Create a new application
      • Go to "Bot" section, click "Add Bot"
      • Copy the token and paste in .env file


STEP 3: INSTALL DEPENDENCIES
────────────────────────────
Run one of these commands:

Windows (PowerShell or Command Prompt):
  pip install -r requirements.txt

macOS/Linux:
  pip3 install -r requirements.txt

Or use the startup scripts:
  Windows:  Double-click run.bat
  Unix:     bash run.sh


STEP 4: RUN THE SYSTEM
─────────────────────
Choose one method:

METHOD A - Using Startup Script (RECOMMENDED):
  
  Windows:  Double-click run.bat (or run in command prompt)
  Unix:     bash run.sh (or chmod +x run.sh && ./run.sh)

METHOD B - Direct Python:
  
  python main.py
  (or python3 main.py on macOS/Linux)

═══════════════════════════════════════════════════════════════════════════════
                        TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

❌ ERROR: "Port already in use"
   Solution:
   • Windows: netstat -ano | findstr :30326
   • macOS/Linux: lsof -i :30326
   • Kill the process and restart

❌ ERROR: "Module not found"
   Solution:
   • Run: pip install -r requirements.txt
   • Or: pip install -r requirements.txt --upgrade

❌ ERROR: "DISCORD_TOKEN not found"
   Solution:
   • Check if .env file exists in project root
   • Add your Discord token to .env file
   • Restart the application

❌ ERROR: "Python not found"
   Solution:
   • Reinstall Python from https://www.python.org/
   • Make sure "Add Python to PATH" is checked
   • Restart your terminal/command prompt

❌ ERROR: "Flask app won't start"
   Solution:
   • Check if port 5000 or 30326 is already in use
   • Try running individual projects first to diagnose
   • Check project requirements are installed
